# Septum audio demonstrations

Every file here is rendered by
[`Tools/RenderDemos.cpp`](../../Tools/RenderDemos.cpp) through the JUCE-free
`septum::Engine` the plug-in runs — the same oscillators, filter,
envelopes, LFOs, effects and documented analog output stage, at 44.1 kHz. No
samples, impulse responses, or external processing are involved anywhere. Each
take is normalised to −3 dBFS on its own peak; the pre-normalisation peak
remains visible below. The renderer rejects silence, non-finite output, and
takes that reach the output stage's saturation region.

## Listening against the real instrument

The point of a replica's demos is comparison. Roland still hosts real-unit
recordings of the modelled instrument, and each demo below names the closest
official reference. The official MP3s are played on real hardware (with
unknown mastering), so they are by-ear references, not measurement targets.

- Official patch demos (17 + a song demo):
  [roland.com SH-201 song list](https://www.roland.com/global/products/sh-201/songlist/)
- The 2007 additional-patch mini-site with 33 more demos, including a
  supersaw comparison recording:
  [rolandus.com SH-201 patches](https://www.rolandus.com/go/sh-201_patches/)
- A no-narration real-unit run-through on video:
  [Roland SH-201 Demo, No Talking](https://www.youtube.com/watch?v=BfDj8V3MTCo)

The demos play this project's original presets, not Roland's factory patch
data (which no public document publishes), so a comparison judges the
*engine's* character — the seven-saw spread trajectory, the FB-OSC growl, the
filter's resonance behavior, envelope snap, effect texture — rather than
patch-for-patch identity. What is settled versus voiced in that engine is
recorded in the [research contract](../sh201-replica-research.md).
