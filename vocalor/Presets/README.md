# Vocalor presets

The current plug-in stores its
[20-parameter control state](../README.md#interface-and-controls) in the host
session and exposes the version-1 defaults on first launch. The seven parameters
added in 1.1 are appended after the original 13 and all default to a neutral
setting, so a session saved by version 1 recalls unchanged. Factory preset files
are intentionally not baked into the project yet: keeping them out avoids
silently changing sound design while the synthesis parameters are still evolving.

When presets are added, use names that describe the voice rather than a real
person (for example `Intimate Alto`, `Warm Bass Choir`, or `Airy Minor Pad`).
Only include original settings and assets that are cleared for redistribution.
