# Drumalor — decision log

Directions chosen by ear, recorded per the A–Z listening-test convention in
the repository's `CLAUDE.md`. A choice made by ear is recorded as made by ear,
never written up as though a measurement had settled it.

**No by-ear decisions have been recorded yet.** Drumalor is an original sound
architecture rather than a calibrated replica of a particular unit, so its
character controls are voiced sound design throughout and there is no
measurement waiting to replace them. Where the engine follows a published
circuit analysis — the two cymbal channels — the analysis fixes the values, and
those citations sit in the source beside the code that uses them.
