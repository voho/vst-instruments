# Fidelity-fix listening takes

Generated by `YouKnow106RenderFidelityFixes`, run once before a fix and
once after it. Both stages are level-matched to the same peak, so an A/B
is a comparison of character rather than of loudness; `-diff` is their
sample difference.

These takes compare two *builds*. The SOTA comparison renders next door
compare two settings of one engine flag, which cannot show a change that
removes a mechanism outright -- afterwards there is no flag left to
switch.

Every take uses the shipped panel with `Unit Character` at its default, so
they describe what a player hears rather than a pristine reference.

The before take is compared through a 16-bit file, so an unchanged build
still measures about -80 to -90 dBc. That is the floor of this measurement,
not a difference -- and it is below audibility, so a change that lands in it
is a change nobody can hear.
