leaves every other one at its shipped setting; `Unit Character` stays at its
default in both takes, so the pair isolates the named feature rather than the
whole character layer.

`-before` and `-after` share one gain, so they are level-matched for A/B
listening. `-diff` carries that same gain, so its loudness relative to the pair
is its true loudness -- a diff that is inaudible in the file is inaudible in the
instrument. The columns below are the diff measured against the before take's
